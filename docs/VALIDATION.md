## 2026-11-10: automatic in-memory matching

- Added `delta(Signature, target, basis_size, max_candidate_checks, max_delta_size)`. Old file size is explicit caller metadata: block count is validated, and short-tail window size is derived from it. The generator has no basis-byte argument or file I/O.
- Full and short-tail windows use seeded RK rolling checksums followed by BLAKE2 confirmation. Adjacent COPY ranges coalesce. Global comparison exhaustion falls back to literal target data; delta byte-budget exhaustion returns an error. It does not silently exceed the requested size.
- Local Windows checks, builds and 14 core test groups passed on JS, Native and Wasm-GC. Tests include 640 deterministic edit/configuration combinations, shifted short-tail cases, rolling checksum recomputation, strong-checksum mismatch rejection and explicit budget/error paths.
